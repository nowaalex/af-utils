# af-utils/\*

Simple open-source tools that just work _(usually fast)_

## [Virtual scroll](https://af-utils.vercel.app/virtual)

![Virtual scroll opengraph image](website/src/assets/og/virtual.png)

### Features

The framework adapters target React 19.2+, Preact 10.29+, Solid 1.9+, Svelte
5.56+, Lit 3.3+, and Vue 3.5+.

- [vertical](https://af-utils.vercel.app/virtual/examples/react/list/simple) / [horizontal](https://af-utils.vercel.app/virtual/examples/react/list/horizontal) / [grid](https://af-utils.vercel.app/virtual/examples/react/hook/grid) / [custom](https://af-utils.vercel.app/virtual/examples/react/hook/custom-render) modes
- [dynamic item sizes](https://af-utils.vercel.app/virtual/examples/react/list/variable-size-list)
- [sticky header and footer](https://af-utils.vercel.app/virtual/examples/react/list/sticky-header-and-footer)
- [scrollToIndex method](https://af-utils.vercel.app/virtual/examples/react/list/scroll-to-item)
- [load on demand](https://af-utils.vercel.app/virtual/examples/react/list/load-on-demand)
- [window scroll](https://af-utils.vercel.app/virtual/examples/react/hook/window-scroll)
- [material-ui](https://af-utils.vercel.app/virtual/examples/react/list/material-ui) / [bootstrap](https://af-utils.vercel.app/virtual/examples/react/list/bootstrap) integration
- [React](https://af-utils.vercel.app/virtual/examples/react/list/simple) / [Preact](https://af-utils.vercel.app/virtual/examples/preact/list/simple) / [Solid](https://af-utils.vercel.app/virtual/examples/solid/list/simple) / [Svelte](https://af-utils.vercel.app/virtual/examples/svelte/list/simple) / [Lit](https://af-utils.vercel.app/virtual/examples/lit/list/simple) / [Vue](https://af-utils.vercel.app/virtual/examples/vue/list/simple) adapters
