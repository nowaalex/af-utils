# Getting started

When you need to render a list or grid with a lot of rows or columns, you may face performance problems.
A lot of DOM nodes must be created, but only a few of them are visible.
One way to optimize this is called **virtual scroll**.
Based on scroll position and size of each item we can calculate the range to show.
Only visible elements are rendered with this approach.

## Installation

Install desired adapter using your package manager

- ### React

    The React adapter supports React 19.2 or newer within the React 19 major release. Older React versions are not supported.

    ```bash
    npm install @af-utils/virtual-react react@^19.2.8
    ```

- ### Solid

    The Solid adapter uses fine-grained range updates and requires Solid 1.9 or newer.

    ```bash
    npm install @af-utils/virtual-solid solid-js@^1.9.14
    ```

- ### Preact

    The Preact adapter exposes a compact component and hooks that follow the React adapter's model ownership.

    ```bash
    npm install @af-utils/virtual-preact preact@^10.29.8
    ```

- ### Svelte

    The Svelte adapter uses readable stores and actions, so only the rendered range participates in updates.

    ```bash
    npm install @af-utils/virtual-svelte svelte@^5.56.9
    ```

- ### Lit

    The Lit adapter provides reactive controllers and directives for web components.

    ```bash
    npm install @af-utils/virtual-lit lit@^3.3.0
    ```

- ### Vue

    The Vue adapter provides composables, a list component, and a virtual-item directive.

    ```bash
    npm install @af-utils/virtual-vue vue@^3.5.0
    ```

- ### Core (no framework)

    Library core is just housing sizes and offsets, so rendering falls on your shoulders.

    ```bash
    npm install @af-utils/virtual-core
    ```

## Typescript

Library core and adapters are written in [Typescript](https://www.typescriptlang.org/) with [TSDoc](https://tsdoc.org/) comments.
This results in good [IntelliSense](https://code.visualstudio.com/docs/editor/intellisense)
