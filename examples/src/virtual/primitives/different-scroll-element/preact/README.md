The framework-neutral layout adapter measures the stable size element as the items container. You can also call [VirtualScroller.setContainer](https://af-utils.vercel.app/virtual/reference/virtual-core/classes/VirtualScroller#setcontainer) directly when rendering something before the virtual items. This is also useful in the [window scroll](https://af-utils.vercel.app/virtual/examples/react/hook/window-scroll) scenario.
