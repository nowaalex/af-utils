[List](https://af-utils.vercel.app/virtual/reference/virtual-react/functions/List) header and footer
can have sticky positioning.
Connect them with
[setStickyHeader](https://af-utils.vercel.app/virtual/reference/virtual-core/classes/VirtualScroller#setstickyheader)
or [setStickyFooter](https://af-utils.vercel.app/virtual/reference/virtual-core/classes/VirtualScroller#setstickyfooter) and add `position: sticky` style.
