[useVirtual](https://af-utils.com/virtual/reference/virtual-react/functions/useVirtual) hook
supports [horizontal](https://af-utils.com/virtual/reference/virtual-core/interfaces/VirtualScrollerInitialParams#horizontal) param
for virtualizing columns instead of rows.
All necessary styles are applied to [List](https://af-utils.com/virtual/reference/virtual-react/functions/List) component automatically.
